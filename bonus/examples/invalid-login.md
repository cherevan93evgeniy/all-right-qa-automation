# BONUS-02 — Reject an invalid password

Steps:
1. Open the login page.
2. Enter the standard user's username and the existing invalid password.
3. Submit the login form.

Expected result:
- The browser stays on the login page and the catalog remains hidden.
- The error is visible and reads "Epic sadface: Username and password do not match any user in this service".
- The login form remains visible, both inputs remain editable, and the Login button remains enabled.
